Neighborhood Lounge

A small relaxed Godot project.
Neighborhood Lounge is a laid-back first-person experience focused on atmosphere, where you hang out and let time pass.

You can:
- look around the lounge
- interact with objects like the radio and drink
- see day/night and weather changes

Features:
- Day/Night cycle
- self-inputted/custom radio playlist audio
- weather system (normal, rainy, and windy days)
- daily events system (including normal days)
- customizable options with saved settings
- interactive options (radio, drink, and other object interactions)

Controls:
- mouse: look around
- left click: interact
- middle click: zoom in
- esc: pause menu

Run without Godot (recommended):
1) Download the latest build from [itch.io](https://maple-sticks.itch.io/neighborhood-lounge)
2) Open the downloaded game build and run the executable

Run from source (Godot):
1) Open the project in Godot
2) Run `MainMenu.tscn`
